## 最小充分的人类问题

一个好的 agent 不该问“我该怎么办？”它应该问的是：哪个最小问题一旦得到回答，就能恢复自主推进？这个问题可能是一个事实、一项偏好、一条边界、一次授权、一个验证信号、一份资源，或者一个停止标准。

## Operational mismatches

:::cards
### Observability（可观测性）

agent 缺少任务关键的现实事实或状态，而且无法可靠推断。

### Preference weight（偏好权重）

多个选项都说得通，但排序取决于速度、成本、风险、品味或身份等人类优先级。

### Authority（授权）

agent 可以把动作准备好，但没有授权就不应该发布、发送、删除、购买、承诺或签署。

### Verification（验证）

agent 可以给出候选答案，但缺少测试、样例、证据、专家评审或验收标准。
:::

## 人的角色

- 设定价值函数和不可接受的边界。
- 判断品味、时机、预算和责任。
- 当流畅输出开始跑偏时，识别错误的抽象。
- 授权外部动作，并承担后果。
