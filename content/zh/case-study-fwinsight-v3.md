## 概览

FW-Insight V3（`fwinsight_v3`）是一个因子框架再生案例。这里说的因子框架，是一段自动生成的量化交易逻辑；"再生"就是产出它的下一版改进。系统已经生成过很多版本，也保存了每个版本的回测表现。这个案例要回答的是：这些历史里，哪些经验真的值得拿来塑造下一版；又该怎么把一条真正有用的经验，和一条"听起来不错"的经验区分开。下文里的"V2"和"V3"指框架经验层的前后两代，一条 claim 则指从 V2 继承下来、还要继续检验的候选经验。

## 为什么这个案例值得研究

这个案例值得研究，因为它展示了前面几个案例没覆盖的一种治理动作：**从大量历史生成样本里提取能改变未来生成分布的硬经验**。

`fwinsight_v3` 不是又一个因子生成器，也不是让 LLM 继续"想几个更好的因子框架"。它面对的是一个已经生成过大量版本的因子框架系统。继续随机采样当然还能得到新样本，但这些样本大多还是来自同一个生成分布。真正有价值的问题变成了：

**哪些经验不是漂亮解释，而是真的能改变样本分布、修正方向判断，并指导下一轮因子框架再生？**

这正好是 LLM 状态失配和支持失配在金融工程里最典型的一种形态。LLM 可以总结经验、解释代码、命名模式，也能把看似成功的局部结构写得很像那么回事。但如果这些经验不能在大量样本上改变统计分布，它们就只是软知识。`fwinsight_v3` 的价值，在于把"经验"重新扔回分布里检验。

## 任务为什么高失配

因子框架再生表面上像一个代码生成任务：给模型样本、性能指标和若干经验，让它写出下一版框架。但真正的困难不在语法，也不在把组件拼起来。

::::cards
### 支持失配

高价值框架可能位于原采样分布的低概率区域。继续让 LLM 自然采样，只会更多地回到常见结构、常见解释和常见组合。

### 规格失配

"听起来像好经验"不是目标。经验必须能在样本分布上表现为均值移动、方差收缩、右尾变厚、左尾变薄或方向反转。

### 聚合失配

几万个版本里的局部成功并不会自动累积成再生规则。大量 claim 可能只是同一个信号的重复表达，必须折叠成独立的经验组。

### 状态失配

经验有生命周期。历史上有效、后来衰减或已经被反驳的 claim，不能和当前 live claim 混在一起指导再生。
:::

所以这个案例的重点不是"LLM 能不能写因子框架"，而是"系统怎样判断哪些经验有资格指导下一轮生成"。

## 核心结构：把样本分布变成实验场

`fwinsight_v3` 的核心做法，是把已经存在的大量因子框架样本反过来当成实验场。

它读取已有因子框架版本、性能指标和 V2 claim，不直接相信任何 claim 的自然语言解释，而是为每个 claim 构造一个可检测的实现度谓词 `φ_c`。这个谓词本质上就是一个"实现度"判定：对某个样本逐一检查，它是不是真的具备该 claim 描述的属性。随后系统在全量样本池里切分高实现组和低实现组，比较两组的 Sharpe（夏普比率）、分位数和分布形态。

换句话说，claim 不再靠"说得对不对"活下来，而是靠"它是否真的切开了样本分布"活下来。

下面的流程展示了一条候选经验如何从原始样本一路走到通过检验的硬经验。（其中的分布检验都是常见的统计比较：Mann–Whitney U（MWU）和 Kolmogorov–Smirnov（KS）判断两组是否存在差异，Levene 判断离散程度是否不同，q90 比较第 90 分位的尾部。）

## 从软知识到硬经验

`fwinsight_v3` 对经验的判断很苛刻。一个 claim 就算在 V2 里得分很高，只要它不能显著区分样本分布，就会被降级为 `SOFT` 或 `UNCLEAR`。反过来，一个 V2 得分不高的 claim，只要它能稳定改变样本分布，也会被提成穿透性知识。

这种苛刻会逼出四个关键动作：

::::cards
### 切割

每条经验都要能把样本池切成高实现组和低实现组。没有可检测实现度的经验，不能直接指导再生。

### 重组

大量自然语言 claim 会被折叠成少数独立信号组。系统关心的是独立经验，而不是重复表述的数量。

### 方向校正

如果高实现组表现更差，经验不会被简单丢弃，而是标记为 `PENETRATING_REVERSED`。这类结果尤其有价值，因为它指出了原系统可能系统性误信的方向。

### 成熟度过滤

live claim、decayed claim 和 refuted claim 必须分开。只有仍处于当前有效状态的经验，才适合进入下一轮再生约束。
:::

这就是"硬经验"的定义：它不是更会说的经验，而是能在大量样本上改变分布、暴露方向，而且经得起当前状态过滤的经验。

## 这个案例最有价值的发现

从已经实现的阶段看，`fwinsight_v3` 最重要的发现不是"找到了很多经验"，恰好相反：大量看似有用的经验，在统计治理之后会收缩成很少的独立信号。

Stage 01 在 1400+ 样本和 77 条 V2 claim 上做分布检验，初看有一批 `PENETRATING` 结果。但 Stage 02 把重复 claim 折叠后，真正独立的强信号只剩少数：例如 market-state awareness 得到确认，而 AdaptiveThresholdManager 相关 claim 出现方向反转。Stage 03 再加 maturity filter 后，系统进一步区分 live 经验和历史污染。

这说明 V3 的价值不在于扩大经验数量，而在于压缩经验熵：

```text
大量生成版本
-> 候选经验和 claim
-> 实现度切割
-> 分布检验
-> 独立信号折叠
-> 方向校正
-> maturity filter
-> 少量硬经验
```

这些硬经验不需要很多，只要少量采用，就可能把下一轮因子框架再生推离旧采样分布。它们不是提示词里的装饰性建议，而是生成约束、反模式、组件组合边界和方向禁忌。

## 边界：它不是完整再生闭环

这个案例要写准，需要保留一个边界：`fwinsight_v3` 本身更像是再生前的硬经验提取层和证据规格层，而不是完整的"生成 - 回测 - 再生成"闭环。

它已经完成的部分是：

- 从历史样本池中抽取可统计检验的经验；
- 判断 claim 是否真正穿透样本分布；
- 把重复 claim 折叠成独立信号组；
- 识别 confirmed / reversed / soft / unclear；
- 用 maturity filter 避免历史 claim 污染当前再生；
- 输出可供后续 V4 或再生器消费的反模式、方向信息和经验接口。

因此，案例结论不应该是"V3 已经证明了完整因子框架再生闭环"，而应该是：

**V3 证明了再生前最关键的一步：如何从旧采样分布中提炼少量能改变未来采样方向的硬经验。**

## 对本站框架的映射

`fwinsight_v3` 也可以很清楚地映射回本站的原始失配框架。

::::cards
### Support：突破旧采样分布

继续从同一个生成器采样，只会反复落在原分布高概率区域。硬经验的作用是改变下一轮采样的约束，让生成进入旧分布之外的区域。

### Specification：拒绝漂亮解释

LLM 的解释、V2 的高 utility、甚至成功样本中的自然语言 claim，都不能直接当作真经验。只有能改变统计分布的 claim 才能升级。

### Aggregation：折叠重复经验

几万样本会产生大量相似 claim。V3 把它们合并成独立信号组，防止"重复出现很多次"伪装成"真的有很多证据"。

### State：区分 live 与 historical

经验不是永久真理。V3 用 maturity filter 把 ObservedFact、Decayed 和 Refuted 分开，避免用过期经验指导当前再生。

### Fitting Boundary：不要绑定单一解释

重复出现的 claim、高 utility 分数或漂亮因子叙事，都可能只是对历史样本过拟合。V3 要求 claim 经过证据组、成熟度状态和分布改变检查，才能指导后续生成。
:::

## 与其他案例的关系

这个案例让案例库多了一类很关键的样本。

1. **Story Insight V4**：把故事生成从最终文本空间改写成控制空间治理。
2. **Story Insight V6**：在控制空间之上处理分层归因、连续性审计、平台期和回退。
3. **Stock Rec V3**：在金融策略生产里限制 LLM 权限，只允许经过 shadow、promotion 和 active 的对象影响生产。
4. **FW-Insight V3**：在因子框架再生前，从大量历史生成样本中提取能改变下一轮采样分布的硬经验。

如果说 Stock Rec V3 的关键词是"生产权"，那么 FW-Insight V3 的关键词就是：

**硬经验，而不是更多采样。**

## 案例结论

`fwinsight_v3` 很适合做成一个新的案例。它展示了一个很重要、也有点反直觉的判断：当系统已经生成过大量版本后，继续要求 LLM "再生成一些更好的"，往往不是最关键的动作。更关键的是把旧样本分布切开、重组、验证、折叠和方向校正，从中提炼出少量真正能指导再生的硬经验。

这个案例适合放在 Stock Rec V3 之后。Stock Rec V3 说明金融策略系统必须治理生产权；FW-Insight V3 则进一步说明，金融工程里的知识本身也要被治理，只有真正穿透分布的经验，才有资格进入下一轮因子框架再生。
