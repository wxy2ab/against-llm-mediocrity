# GLM Coding 10:00 购买窗口助手

这是一个本地 Tampermonkey 用户脚本。它只做三件事：

1. 在北京时间 10:00 刷新 GLM Coding 页面；
2. 套餐仍售罄或页面繁忙时，以 750ms 间隔有限重试；
3. 找到目标套餐后点击一次，购买窗口出现后停止，由你手动确认和付款。

它不会调用网站内部接口、绕过验证码、自动确认订单或自动付款。

## 安装

1. 在 Chrome 安装 Tampermonkey。
2. 打开 Tampermonkey 的“添加新脚本”。
3. 删除编辑器里的模板，粘贴 `glm-coding-rush.user.js` 的全部内容并保存。
4. 打开并登录 <https://bigmodel.cn/glm-coding>。

## 每天使用

1. 建议 9:50 前完成登录和实名认证，并关闭系统睡眠；9:59 后把该标签页保持在前台，避免 Chrome 降低后台计时器精度。
2. 页面右下角选择要购买的 Lite、Pro 或 Max。
3. 点击“测试定位”；正确的套餐按钮应该滚动到画面中并闪红框。
4. 点击“启动”。面板会显示下一次北京时间 10:00。
5. 不要关闭这个标签页；购买窗口弹出后，脚本自动停止，你手动付款。

## 可调整参数

脚本顶部 `CONFIG` 中：

- `retryDelayMs: 750`：每次检测到售罄/繁忙后的等待时间；
- `retryWindowMs: 120_000`：最多重试两分钟；
- `maxRetries: 80`：最多刷新次数。

不建议将重试间隔调到 500ms 以下，也不要同时启动多个标签页。高频请求可能触发网站限流或风控。
