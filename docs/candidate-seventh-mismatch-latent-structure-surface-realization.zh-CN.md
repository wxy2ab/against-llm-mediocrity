# 潜在结构—表层实现失配

## 候选第七类现象工作稿：完整内部控制、稀疏外部表征与受控接收者推断

**状态：候选现象文档 v0.1**  
**分类纪律：暂不纳入六类原始失配，不修改现有 taxonomy**  
**主要来源：长篇故事创作中的暗线、潜台词、隐性价值结构与读者推断问题**  
**候选英文名：Latent-Structure–Surface-Realization Mismatch**  
**暂用简称：隐显失配**

---

## 摘要

高质量写作不仅依赖克制、留白、空镜、节奏和语言质感等可直接观察的一级品味，还依赖大量不应被完整写入成品、却必须持续控制成品的二级和三级结构：人物未说出口的动机、完整但未正面展开的支线、离场发生的事件、隐性价值观、错误信念、关系债务、迟延兑现的承诺，以及读者应在不同阶段形成的怀疑、误判和重估。

这类结构具有一种特殊的不对称性：

```text
内部控制强度必须高；
外部直接显化强度必须低；
跨场景因果影响必须持续；
接收者又必须能够从少量分布式证据中逐步重建它。
```

简单地“把暗线写清楚”并不能解决问题。暗线一旦以高显著度进入共享生成上下文，模型可能把原本应当作为作者侧控制结构的内容直接解释进正文；如果不写，则暗线又容易消失、断裂或仅成为无效设定。系统于是常在“没有真正暗线”和“把暗线说破”之间振荡。

本文暂将这一现象称为**潜在结构—表层实现失配**。它可能意味着价值保存管线中存在一个尚未被单独展开的站点：

```text
完整潜在控制结构 H
  → 受披露策略约束的表层实现 Y
  → 接收者随时间形成的解释分布 q_t
```

但当前证据不足以把它宣布为第七类原始失配。现有聚合失配已经覆盖隐藏约束、长程关系、全局不变量和 rendering；状态、支持、规格与拟合边界失配也可能解释该现象的重要部分。因此，本文的任务不是扩张 taxonomy，而是冻结现象、给出候选定义、建立与六类失配的边界，并声明后续需要什么最小对、干预和测量，才能判断它究竟是：

1. 聚合失配中的潜在结构实现子型；
2. 聚合、状态、支持、规格等失配的复合现象；
3. 一条独立的机制轴；
4. 或者真正独立的第七个价值保存失败站点。

当前最保守而有用的结论是：**高价值生成有时不要求把内部价值结构完整传输到输出，而要求完整结构以低带宽、分布式和时序化的方式控制输出。**

## 1. 为什么需要先记录这个候选现象

现有六类原始失配通过世界到输出的价值保存管线组织：

```text
S_world
  → observation
  → representation
  → belief / state
  → capability routing
  → candidate support
  → aggregation
  → evaluation
```

它们分别回答：决定性变量是否进入表征，信念是否忠于证据，正确能力是否被激活，高价值候选是否可达，局部部分能否组成全局对象，以及评价目标是否代表真实效用。详见：

- [六类原始失配：从管线推导出的分类法](./six-primitive-mismatches-pipeline-derived-taxonomy-llm-systems.zh-CN.md)
- [聚合失配与组合治理](./aggregation-mismatch-compositional-governance-llm-systems.zh-CN.md)
- [状态失配与状态治理](./state-mismatch-state-governance-llm-systems.zh-CN.md)
- [支持失配与控制空间搜索](./support-mismatch-control-space-search-llm-systems.zh-CN.md)
- [规格失配与目标治理](./specification-mismatch-objective-governance-llm-systems.zh-CN.md)

这套 taxonomy 有意保持克制。一个现象只有在占据独立结构站点、需要不可替代的修复目标，并能构造保持其他站点近似不变的最小对时，才有资格成为新的 primitive。

因此，本工作稿不主张“已经发现第七类失配”。记录它的原因是：故事创作暴露了一种现有描述不够精确的价值保存要求。这个要求不是单纯让更多结构进入最终对象，而是让一个完整结构：

```text
存在于作者侧；
持续约束局部选择；
不被直接复制到读者侧；
却能够通过结果让读者逐步推断其存在。
```

如果现在不单独记录，这种现象很容易被粗略地归入“长程一致性”“隐藏约束”或“写得不够含蓄”，从而失去最有价值的研究问题：**内部控制与外部表达是否需要两套不同强度、不同权限和不同验证条件的表征？**

## 2. 从一级品味到二级、三级品味

### 2.1 一级品味：可以直接观察的成品属性

很多写作品味可以直接在成品上描述和审计：

```text
克制
留白
空镜
减少解释
避免煽情
节奏有张有弛
对白不过度承载信息
不重复主题
```

这些要求主要作用在最终文本 `Y` 上。系统可以检查某个句子是否解释过度、某段是否冗余、某个场景是否缺少呼吸空间。

### 2.2 二级品味：完整但不应完整出现的生成原因

更深一层的质量来自读者未必直接看见、但能够感觉到其因果存在的结构：

```text
人物一直在弥补一件从未被正面说明的旧事；
一条未完整展开的支线解释了多个看似独立的选择；
角色表面争论利益，实际在确认忠诚是否仍然存在；
故事从未宣告某种价值观，但事件选择持续受到它约束；
一个物件多次出现，不是象征装饰，而是关系债务的物理载体。
```

这些对象不是简单的“正文内容”。它们首先是决定正文为什么这样选择的**潜在生成结构**。

### 2.3 三级品味：对接收者推断轨迹的控制

更高一层还包括：

```text
读者什么时候只应感觉到异常；
什么时候可以形成两个竞争性解释；
什么时候应重新理解前文；
哪些事实直到结尾仍不应被完全确认；
哪些暗线必须可重建，但不能被一句话解码。
```

这不只是隐藏信息，而是对接收者信念演化过程的设计。优秀叙事并非简单追求“读者不知道”，而是在不同时间让读者处于不同的、经过设计的后验区间。

因此，可以暂时把三层区分为：

| 层级 | 主要对象 | 核心问题 |
|---|---|---|
| 一级品味 | 表层文本性质 | 成品看起来和读起来怎样？ |
| 二级品味 | 作者侧潜在结构 | 哪些未说出的关系持续决定表层选择？ |
| 三级品味 | 显化与推断策略 | 接收者在什么时间、以何种确定度理解什么？ |

这不是完整的文学理论，只是为了隔离当前候选现象所需的最小结构。

## 3. 核心现象：高控制、低显化

该候选现象的中心不是“信息被隐藏”，而是两种强度必须被解耦：

```text
control strength      = 潜在结构对生成决策的控制强度
surface explicitness  = 潜在结构在最终成品中的直接陈述强度
```

高价值暗线要求：

```text
control strength      高
surface explicitness  低
```

同时还要求：

```text
causal imprint        高
reader inferability   非零且受控
premature certainty   低
```

由此得到四种典型状态：

| 控制强度 | 显化强度 | 典型结果 |
|---:|---:|---|
| 高 | 低 | 真正的潜台词、暗线、余韵和可重建深层结构 |
| 高 | 高 | 解释性写作、主题泄漏、人物自我解说、把暗线说破 |
| 低 | 低 | 空洞、假留白、随机模糊、没有底层故事 |
| 低 | 高 | 口号、标签、装饰性深刻、显式设定替代真实结构 |

当前 LLM 写作经常能够生成第一层品味的表面迹象，却难以稳定进入“高控制、低显化”区域。它可能做到克制的句子，但没有一个完整潜在结构持续约束这些句子；也可能建立完整设定，却不断通过旁白、心理描写或对白把设定直接泄漏出来。

这说明“少写”与“隐藏结构真实存在”不是同一件事：

```text
留白不等于没有写；
留白要求被省略的部分在作者侧仍然完整存在，
并对已经写出的部分产生可追踪的因果影响。
```

## 4. 这不是普通的“隐藏约束更多”

如果问题只是约束数量多、跨度长、局部决策难以兼顾全局，那么现有聚合失配足以描述：把依赖图、承诺—兑现关系、时间线和全局不变量显式化，然后通过组合治理与全文审计保存它们。

本候选现象更特殊的地方在于：

```text
潜在结构必须被完整保存，
但完整保存的对象不应完整进入最终交付面。
```

也就是说，作者侧和读者侧不应共享完全相同的表征权限：

```text
作者侧需要：完整因果模型、隐藏事件、真实动机、支线全貌、披露计划。
读者侧需要：有限场景、行为痕迹、物件、停顿、矛盾、迟延回收和可推断证据。
```

因此，错误方案有两种：

```text
方案 A：不建立完整暗线
→ 最终成品缺乏真正深层结构。

方案 B：把完整暗线作为高显著度说明反复提供给写作器
→ 模型稳定遵守暗线，但把暗线直接写入正文。
```

候选正确方向是：

```text
完整暗线进入作者侧控制状态；
显化合同决定每个时点允许暴露什么；
局部写作器只获得当前场景所需的投影；
最终成品接受作者侧和读者侧两种不同信息条件下的审计。
```

这提示当前问题可能不是“外化或不外化”的二选一，而是：

> **把结构外化到正确的控制面，同时防止它未经变换地泄漏到交付面。**

## 5. 候选管线与形式化

### 5.1 扩展的叙事管线

对具有暗线、潜台词或受控披露要求的生成任务，可以暂时使用以下扩展：

```text
K
  → H
  → D
  → R(H, D)
  → Y
  → q_reader(h | Y_≤t)
  → U
```

其中：

```text
K        = 已获得的人物、事件、主题、物件、场景与关系候选
H        = 作者侧完整潜在结构
D        = 披露 / 显化策略与时间表
R        = 表层实现算子
Y        = 接收者实际看到的成品
q_reader = 接收者随文本进展形成的潜在结构解释分布
U        = 真实任务效用或叙事价值
```

`H` 可以包括：

```text
hidden events
true motivations
private beliefs
false beliefs
off-screen changes
relationship debts
latent value commitments
complete side arcs
unresolved promises
causal links
```

`D` 可以包括：

```text
reader_may_know
reader_may_suspect
reader_must_not_know
allowed_traces
forbidden_exposition
clue_strength
ambiguity_set
reveal_window
payoff_status
```

### 5.2 目标条件

高价值实现至少同时满足四类条件。

第一，潜在结构自身完整：

\[
\operatorname{Cons}(H) \geq \tau_c.
\]

第二，潜在结构对表层有真实控制作用。改变 `H` 应当在保持主情节骨架近似不变时，系统性改变一组分布式表层选择：

\[
\operatorname{Imprint}(H \rightarrow Y) \geq \tau_i.
\]

第三，潜在命题不能被过度直接陈述：

\[
\operatorname{Leak}(H,Y) \leq \tau_\ell.
\]

第四，接收者在各时点形成的解释分布应落在目标区间内：

\[
q_t \in \mathcal{Q}^{\star}_t.
\]

这里的 `Q_t*` 不一定要求接收者猜中唯一答案。它可以要求：

```text
早期只感到异常；
中期保留两个合理解释；
后期提高对正确暗线的概率；
结尾完成重估，但仍保留有限不确定性。
```

因此，目标不是简单最大化信息隐藏或信息传输，而是同时满足：

```text
完整潜在结构
强因果印记
低直接泄漏
目标化接收者推断轨迹
```

### 5.3 候选失配定义

可以暂时定义：

> **潜在结构—表层实现失配**发生在：任务要求一个高带宽潜在结构对生成保持强而持续的控制，同时只允许其通过低带宽、分布式和时序化的表层证据被接收者间接重建；但当前系统不能稳定解耦控制强度与显化强度，因而在潜在结构丢失、表层无因果印记、过度解释、错误披露时序或接收者误推断之间振荡。

这是一个候选定义，不是已经成立的 primitive 定义。

### 5.4 任务属性与系统失配必须区分

“任务需要高内部带宽、低外部带宽”只是任务属性，不等于系统已经失配。

只有当：

```text
存在可行的实现或治理干预 R'，
能够在相近成本和授权约束下更好地满足上述联合条件，
而当前系统的 R 无法达到，
```

才能谈系统层的可修复失配。

如果任何可行作者或系统都无法从现有故事材料中生成这种效果，那可能是任务不可识别、规格不可判定或能力不足，而不能仅凭结果不好就命名新的失配。

## 6. 为什么它可能只是聚合失配的补充

现有聚合失配已经覆盖：

```text
long-range consistency
hidden constraints
future commitments
nonlocal reference binding
global invariants
rendering
parts-to-whole composition
```

从这个角度，可以把本候选现象直接写成一种更复杂的组合要求：

```text
最终 Y 必须同时保存：
1. H 内部的关系；
2. H 对局部表层选择的影响；
3. 禁止直接陈述 H 的约束；
4. 跨时间披露顺序；
5. 接收者可推断但不可过早确定的全局不变量。
```

那么它仍然可能只是：

> **聚合失配中的潜在结构实现子型**，即组合算子不仅要组合内容，还要组合“可见”与“不可见”的关系。

这种解释具有很强合理性。尤其在以下情况下，不应增加第七类：

1. 只要建立完整 `H`、披露图与组合不变量，普通组合治理就能稳定解决；
2. 不需要新的治理对象，只需要把 `forbidden_exposition`、`clue_timing` 和 `reader_inference` 加入已有 composition invariant；
3. 失败程度主要由长程耦合、分支数量和跨场景依赖负荷预测；
4. 在完整全文上做全局审计与有界修复，已经能够处理主要 residual；
5. 所谓 `H → Y` 站点不能构造与 `K → Y` 聚合站点独立的最小对。

因此，当前最强的默认假设仍应是：

```text
它首先是聚合失配的候选扩展，
只有在独立干预证据出现后，才考虑升格。
```

## 7. 与现有六类失配的边界

一个故事没有暗线，并不自动意味着发生本候选失配。应先定位更上游、已有的失败。

| 观察到的失败 | 更优先的诊断 |
|---|---|
| 暗线、人物秘密或离场事件从未进入系统可访问表征 | 观测—表征失配 |
| 暗线已经提供，但跨场景被忘记、误更新、错误塌缩或与当前阶段脱节 | 状态失配 |
| 系统具备潜台词写作能力，却因表面提示触发成“解释主题”或“总结人物动机” | 拟合边界失配 |
| 微妙、分布式、非陈述性的实现方式很少成为活候选 | 支持失配 |
| 暗线内部、人物动机、时间线、支线与主线关系不完整或互相矛盾 | 聚合失配 |
| 评价器只奖励清楚、完整、主题明确，因而系统被鼓励把隐性结构说出来 | 规格失配 |
| `H`、`D`、目标与候选条件已近似固定，但实现器仍不能同时保持强控制、低泄漏与目标读者推断 | 候选潜在结构—表层实现失配 |

一个更严格的候选最小对应当是：

```text
Same observation
Same representation
Same belief / state
Same activated capability
Same candidate support
Same latent structure H
Same disclosure target D
Same objective
Different realization operator R
Different leakage, reader inference, and global utility
```

如果无法构造这样的最小对，该现象就不应成为新的原始失配。

## 8. 候选机制假说：控制—表达显著度耦合

“LLM 的认知强度都是一致的”是一个有启发性的直觉，但不宜直接作为理论主张。模型内部是否存在统一认知强度、低成本潜意识或人类式后台思维，目前都缺少可操作定义。

更稳健的机制假说是：

> **在共享 token 通道中，提高一个潜在结构对生成的控制显著度，往往也会提高它进入表层表达的显著度。**

可以称为：

> **控制—表达显著度耦合**  
> Control–Expression Salience Coupling

为了让暗线稳定生效，系统常采取：

```text
反复重述暗线；
详细解释真实动机；
提高它在 prompt 中的篇幅；
要求模型始终牢记；
在每个场景重复相关背景。
```

这些操作可能同时提高：

```text
P(暗线影响局部生成)
以及
P(暗线被旁白、对白或心理描写直接说出)
```

而任务需要的是：

```text
control salience  ↑
surface salience  ↓
```

因此，控制—表达显著度耦合可以解释系统为何在“忘记暗线”和“泄漏暗线”之间形成 trade-off。

但该耦合目前只是一条机制假说，不是第七类失配本身，也不能被宣称为自回归架构的必然定理。它需要通过显著度剂量实验、跨模型重复和通道分离干预来验证。

## 9. 候选治理方向：潜在—表层双层治理

如果该现象真实存在，一个合理的解决方向不是把暗线写得更长，而是把作者侧控制结构与接收者侧交付结构分开治理。

### 9.1 作者侧潜在结构账本

作者侧维护完整 `H`：

```text
真实发生过什么；
每个人知道什么、不知道什么、误以为什么；
人物为何做出当前选择；
哪条支线在离场继续发展；
哪些关系债务尚未兑现；
哪些价值承诺只能通过行为体现；
哪些表层痕迹由哪个潜在原因产生。
```

它应尽量成为结构化任务对象，而不是一篇充满文学解释的背景说明。

### 9.2 显化合同

`D` 规定：

```text
当前场景允许读者知道什么；
允许怀疑什么；
必须继续不知道什么；
可以使用哪些痕迹；
禁止使用哪些直接解释；
本场景的线索强度；
本场景应保持的歧义集合；
后续在哪个窗口允许兑现。
```

### 9.3 场景局部投影

写作器不必在每一场完整重读全部 `H`，而可以从权威潜在状态生成当前场景的最小充分投影：

```text
当前相关的隐藏状态；
必须影响的行为与选择；
允许出现的证据；
禁止直接陈述的命题；
需要保存到未来的承诺；
与其他场景共享的不变量。
```

这可能是“低成本维护暗线”的系统级近似：不是让模型拥有类人的低认知后台，而是由外部状态层保存完整结构，只把当前必要投影加载到局部生成面。

### 9.4 双侧审计

必须区分两个信息条件不同的 auditor。

**作者侧审计：**看 `H + D + Y`，检查：

```text
暗线是否完整；
行为是否真的由 H 支持；
支线是否持续；
表层痕迹是否有因果来源；
是否出现与隐藏状态冲突的行为。
```

**接收者侧审计：**只看 `Y`，检查：

```text
是否可以从分布式证据中重建；
是否出现直接解释；
是否过早确定；
是否始终不可判断；
解释轨迹是否符合 D；
模糊是否来自真实结构，而不是随机缺失。
```

只有作者侧审计，系统可能生成逻辑完整但解释过度的文本。只有接收者侧审计，系统可能把随机模糊误判为深度。二者应共同形成验收条件。

### 9.5 这不是保存模型隐藏思维

作者侧 `H` 是任务所需、可检查、可修订、可版本化的故事对象，不是要求保存模型的自由形式 chain-of-thought。

```text
H 应回答：故事世界中什么为真，以及什么应如何影响成品。
H 不需要记录：模型内部逐 token 如何想到这些内容。
```

## 10. 典型失败形态

以下现象可以作为工作性症状，但暂时不应被视为独立子类。

### 10.1 潜在结构缺失

表面有留白，但作者侧没有完整原因。读者无法通过回看重建任何稳定结构。

### 10.2 潜在结构泄漏

真实动机、主题或过去事件被旁白、对白、心理描写直接解释。

### 10.3 惰性设定

`H` 存在于 outline 或 prompt 中，但对具体动作、物件、停顿、误解和场景选择几乎没有因果影响。

### 10.4 披露时序错误

线索过早集中、结论提前确定，或关键证据过晚出现，导致所谓反转只是补充新信息而非重估旧信息。

### 10.5 线索集中坍缩

系统把本应跨多个场景分布的痕迹一次性塞进某段对白或独白。

### 10.6 随机模糊

文本缺少解释，但不是因为完整结构被克制地实现，而是因为因果关系根本没有建立。

### 10.7 单一符号过载

一个物件或意象承担全部暗线表达，导致象征意图过于明显，且缺少行为与事件层的多通道印记。

### 10.8 作者正确、读者不可重建

作者侧逻辑完整，但成品提供的痕迹过弱、无区分性或与其他解释同样兼容，读者无法获得目标推断。

## 11. 最小实验设计

后续判断该现象的分类地位，最重要的是先固定 oracle 潜在结构，避免把“暗线生成失败”和“暗线表层实现失败”混在一起。

### 11.1 实例生成器

每个实例至少包含：

```text
M = 可见主情节骨架
H = 完整隐藏支线或潜在关系模型
D = 披露与读者推断时间表
F = 允许出现的表层痕迹集合
X = 禁止直接陈述的潜在命题集合
G = 必须保存的跨场景不变量
```

同一个 `M` 可以配两个反事实潜在结构 `H1` 和 `H2`。高质量系统应在不直接解释差异的情况下，让多个微观选择随 `H` 系统性变化。

### 11.2 核心 treatment

| Treatment | 作者侧结构 | 生成通道 |
|---|---|---|
| Direct | 不提供 oracle `H` | 直接生成全文 |
| Shared-Full | 完整 `H` 以高显著度放入同一 prompt | 要求模型不要说破 |
| Structured-H | `H` 与 `D` 结构化，但写作器仍完整读取 | 单阶段表层实现 |
| Governed-Projection | 外部维护 `H`，按场景投影，并执行双侧审计 | 分层实现与有界修复 |

最关键的比较不是 Direct 与更复杂流程，而是：

```text
Shared-Full / Structured-H
vs
Governed-Projection
```

因为这些条件可以共享同一个 oracle `H`。如果后者在保持潜在完整性的同时降低泄漏、改善读者推断，而前者形成稳定 trade-off，就支持存在一个实现层残差。

### 11.3 核心端点

1. **潜在完整性**  
   给作者侧 auditor 看 `H + Y`，检查人物行为、事件、支线和价值结构是否忠于 `H`。

2. **反事实因果印记**  
   在相同 `M` 下把 `H1` 替换为 `H2`，测量表层细节是否以预期方向系统变化，而不是只替换一句解释。

3. **直接泄漏**  
   检查局部 span 是否直接蕴含被禁止陈述的命题 `X`。

4. **读者重建**  
   只给 reader `Y`，要求在多个竞争性潜在结构中判断、排序或重建最可能的 `H`。

5. **推断时序**  
   分阶段给出前缀 `Y_≤t`，测量读者后验是否按 `D` 演化。

6. **总体成品质量**  
   独立评估人物、节奏、情感、自然度、原创性和编辑就绪度，避免仅优化机制指标。

7. **成本与方差**  
   记录 token、轮次、时延、修改量、跨 realization 方差和失败类型。

### 11.4 关键消融

```text
移除 D，只给 H；
保留 D，但移除作者侧审计；
保留 D，但移除读者侧审计；
每场读取完整 H vs 只读取局部投影；
共享相同 token 预算；
共享相同初始全文，再只改变实现 / 修复算子；
```

### 11.5 需要避免的混淆

- 不要让不同 treatment 自己发明不同质量的 `H`；
- 不要只用“故事好不好”作为唯一端点；
- 不要让看过 `H` 的 judge 充当读者侧 judge；
- 不要把解释更完整误判为暗线更完整；
- 不要把随机模糊误判为低泄漏；
- 不要把同一 prompt 更长造成的质量变化归因于新机制；
- 不要在没有 treatment fidelity 记录时比较多阶段流程。

## 12. 四种可能的最终分类

### 12.1 结果 A：聚合失配的潜在实现子型

支持该裁决的证据包括：

```text
完整 H、D 和组合不变量一旦外化，普通组合治理即可解决；
实现问题可完全写成 aggregation operator A 的约束；
没有独立于组合治理的新修复对象；
失败随长程耦合负荷变化，并被全文审计与 patch 稳定修复。
```

此时，应把本文并入聚合失配文档，作为：

> 潜在结构的受控显化与接收者推断子型。

### 12.2 结果 B：多类失配的复合现象

可能的复合画像是：

```text
聚合：H 内部与跨场景关系难以保存；
状态：H 在长程生成中漂移；
支持：微妙实现候选难以到达；
规格：评价器奖励清楚解释而非含蓄实现；
拟合边界：系统被路由到总结 / 阐释能力；
```

如果分解后的既有干预能够分别解释并修复主要方差，就不需要新的 primitive。本文可保留为一种高价值复合任务画像。

### 12.3 结果 C：独立机制轴，但不是新的原始失配

控制—表达显著度耦合可能是跨越多类失配的组件机制，例如属于：

```text
representation
attention / salience allocation
policy support
action interface
search / execution
```

它可以成为诊断—机制桥接中的新机制变量，而不改变六类价值保存 taxonomy。

### 12.4 结果 D：独立的第七个原始失配

只有满足以下条件，才应考虑升格：

1. 能把价值保存管线稳定拆出 `H → Y → q_reader` 的独立站点；
2. 在其他六个站点近似固定时，只改变 realization / disclosure operator 就能显著改变价值；
3. 现有六类的主要修复目标不能替代该干预；
4. 双层表征、显化合同或接收者后验治理构成不可再约化的新修复目标；
5. 该站点的预测不局限于单个故事案例，并能在其他“高内部带宽—低外部带宽”任务中复现；
6. 能构造明确的撤销条件，说明什么证据会迫使它回归聚合子型或复合失配。

在达到这些标准之前，不使用“第七类原始失配已成立”的表述。

## 13. 超出故事创作的潜在适用范围

该现象最先在故事创作中被观察到，但其抽象可能更广：

```text
教学：教师维护完整解法，但只给最小提示；
谈判：系统维护完整策略，但只公开有限承诺；
产品界面：内部模型复杂，用户只看到最小充分控制；
隐私解释：系统掌握完整敏感信息，但只能给出非泄漏理由；
幽默与悬疑：完整机制必须存在，但效果依赖延迟重建；
外交与组织沟通：内部目标完整，外部措辞受关系与权限约束；
专家建议：专家使用高维模型，但输出只保留行动所需的低带宽结论。
```

这些任务共享：

```text
高内部带宽
低外部带宽
强内部因果控制
受控接收者推断
权限不对称
```

但跨域类比目前只是理论推论，不能作为已经验证的普遍性证据。

## 14. 当前 claim ceiling

### 当前可以主张

- 长篇故事的价值可能依赖完整但不应完整显化的潜在结构；
- “把暗线完整写进生成提示”可能同时提高遵守与泄漏，形成值得验证的 trade-off；
- 作者侧完整性和读者侧可重建性需要不同信息条件下的评价；
- 现有六类管线可能把 `H → Y → reader belief` 压缩在聚合或评价站点中；
- 该现象值得作为候选扩展单独记录并设计最小对实验。

### 当前不能主张

- 第七类原始失配已经成立；
- 自回归模型必然不能维护暗线；
- LLM 没有任何低成本潜在推理；
- 人类写作确实使用某种已知的“低认知后台线程”；
- 双层表征一定优于完整 prompt；
- 控制—表达显著度耦合是架构定理；
- 该现象不能被聚合、状态、支持、规格或拟合边界失配解释；
- 故事中的暗线问题已经推广到教学、谈判、隐私或界面设计。

## 15. 后续关键问题

1. 给定相同 oracle `H` 后，普通全文规划与组合审计是否已经足够？
2. `D` 是否只是规格的一部分，所谓新现象是否本质上是目标函数没有描述读者后验？
3. `R` 是否只是更细的 aggregation operator，而不是独立管线站点？
4. 暗线漂移是否主要由状态维护失败解释？
5. 微妙实现是否主要是支持不足，控制空间搜索即可解决？
6. 把 `H` 结构化并按场景投影，是否真的能同时提高控制与降低泄漏？
7. 控制显著度与表达显著度是否存在稳定的剂量—反应曲线？
8. 作者侧与读者侧 judge 的一致性、分辨率和偏差如何校准？
9. 读者后验 `q_t` 应测唯一答案、排序、置信区间，还是开放解释集合？
10. 什么样的暗线是真实因果结构，什么只是事后可解释的装饰？
11. 该现象是否只在开放式文学质量中成立，还是能构造强 verifier 的受控任务？
12. 是否存在一个不依赖自然语言暗线的简化生成器，用于稳定复现“高控制、低显化”要求？

## 16. 建议命名

### 首选正式名

> **潜在结构—表层实现失配**  
> **Latent-Structure–Surface-Realization Mismatch**

优点是直接描述两个对象与转换，不预设内部认知机制，也不局限于故事暗线。

### 可用简称

> **隐显失配**

适合中文讨论，但正式文档中应始终先给出完整名，避免把它误解成单纯的信息隐藏。

### 暂不建议作为正式名

- **暗线失配**：过于故事领域化；
- **认知强度失配**：对模型内部机制宣称过强；
- **隐藏约束失配**：容易直接与聚合失配重叠；
- **潜意识失配**：拟人化且不可操作；
- **压缩失配**：会与表征压缩、上下文压缩和信息论问题混淆。

### 机制名与失配名分开

```text
候选价值失败：潜在结构—表层实现失配
候选机制解释：控制—表达显著度耦合
候选治理方法：潜在—表层双层治理 / 显化治理
```

三者不应混为同一个概念。

## 17. 冻结陈述

### 一句话现象

> 有些高价值生成任务要求系统完整维护一个不应被完整输出的潜在结构，并让它通过少量、分布式和延迟的表层痕迹持续影响成品。

### 一句话候选失配

> 当系统无法解耦潜在结构的控制强度与其在成品中的显化强度，因而只能在“暗线消失”和“暗线泄漏”之间振荡时，可能存在潜在结构—表层实现失配。

### 一句话分类纪律

> 当前优先把它视为聚合失配的候选补充或多失配复合现象，只有独立站点、最小对与不可替代干预得到证据支持后，才考虑第七类原始失配。

### 一句话工程方向

> 不要把作者侧完整结构未经治理地复制到交付面；应维护权威潜在状态、显化合同、场景投影，并分别进行作者侧与接收者侧审计。

---

## 18. 结论

故事创作暴露了一个值得单独保存的问题：真正丰富的叙事并非只由可见技巧构成。许多决定作品厚度、余韵和完整性的结构，必须在作者侧保持高分辨率和强因果控制，却只能以低分辨率的表层痕迹进入读者侧。

这与“写出更多全局结构”既相连又存在张力。聚合治理要求外化长程关系，防止它们在生成中丢失；隐性叙事又要求这些关系不能未经变换地进入成品。真正的工程问题可能因此不是是否显式化，而是：

```text
向谁显式化；
在哪个控制面显式化；
以什么权限显式化；
通过什么实现算子进入成品；
让接收者在什么时间形成什么解释。
```

目前没有足够证据判断这是否构成新的原始失配。最合理的处理是保持 taxonomy 不变，把它作为候选现象冻结下来，并优先检验它能否被聚合失配的组合治理完整吸收。若 oracle 潜在结构、目标和候选均已固定，而仅改变显化 / 实现算子仍能产生稳定、不可被现有六类干预替代的价值差异，才有理由重新讨论第七类。

在此之前，本文的价值不是命名一个新类别，而是保留一个明确的研究问题：

> **价值结构是否总应完整进入输出，还是有一类任务要求价值在内部完整保存、在外部受控欠显化，并通过接收者推断重新形成？**
