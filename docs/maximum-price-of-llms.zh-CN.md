## 核心结论

用户不为模型的"能力感"、参数规模、推理长度或 token 消耗付款，只为**可验证的增量价值**付款。LLM 在任一任务上的长期最高价格同时受四个上限约束：

```text
P_i^* <= theta_i * r_i(C,G,B) * S_i(C,m_i) * V_i^0 - K_i
```

| 约束 | 符号 | 含义 |
|---|---|---|
| 可靠性上限 | `r_i` | 模型 + 工程治理能否稳定触达可接受结果 |
| 稀缺性上限 | `S_i` | 该能力是否已被市场普及，稀缺租金是否仍存在 |
| 捕获份额上限 | `theta_i` | 价值由工具捕获，还是由 IP、数据、组织、分发捕获 |
| 成本上限 | `K_i` | token、集成、监督、验证、风险成本是否吞噬增量收益 |

四个上限相乘相减，决定了一个反直觉的结果：**模型最容易做好的任务往往最不值钱，最值钱的任务往往模型做不好或捕获不到**。全文围绕这一张力展开。

## 1. 问题：模型能力为什么不等于最高价格

一个常见推断是：模型越强，能完成的任务越多，价格就可以越高。这个推断只在**短期、低普及率、低竞争或专有场景**下成立。长期来看，用户支付的不是模型能力本身，而是**相对次优替代方案的可验证增量效用**。

LLM 的价格受到两种相反力量的挤压：

1. **商品化挤压**：模型能流畅完成的任务，供给迅速扩张。任务从稀缺能力变成基础设施，单位产出的市场价格下降。更关键的是，"次优替代方案"本身也在变化：当竞品工具普及后，客户的对照基线就不再是昂贵的人类，而是便宜的竞品工具，价格被压向竞争均衡。
2. **触达挤压**：模型不能流畅完成的任务，稀缺租金仍然很高，但价值实现依赖隐藏状态、非局部结构、稀有判断、IP、组织流程、审美与工程治理。通用模型既无法独立触达近优解，也无法独立捕获全部价值。

这与"LLM 平庸—局部对齐—LLM卓越"的三阶段任务分类一致：

| 任务类型 | 模型表现 | 价格命运 |
|---|---|---|
| LLM卓越 | 直接输出即近优 | 最快商品化，租金归零 |
| 局部对齐 | 局部正确、全局漂移 | 有真实局部价值，需治理才能变现 |
| LLM 平庸 | 暴力采样也难触达近优解 | 租金最高，但模型捕获不到 |

价格的甜蜜区不在两端，而在中间：**刚刚可达、尚未普及、且工具方能绑定验证与交付**的任务。后文的驼峰曲线和行业估算都是这一判断的展开。

## 2. 单任务定价模型

### 2.1 基本量定义

任务 i 的价值结构：

```text
V_i = 成功完成任务 i 的价值
F_i = 失败、返工、误导或风险造成的损失
H_i = 次优替代方案（人类或传统软件）完成该任务的成本
r_i^H = 次优替代方案的成功概率
```

供给侧三要素：

```text
C = base model capability（基础模型能力）
G = prompt / workflow / tool / governance quality（工程治理质量）
B = test-time compute / sampling / search budget（推理期预算）
```

成本项统一记为：

```text
K_i = K_token + K_integration + K_supervision + K_verification + K_risk
```

即 token 成本、集成成本、人类监督成本、验证成本与风险成本之和。

### 2.2 成功概率：能力受 mismatch 限制的饱和函数

任务成功概率不单由 C 决定，而由 C、G、B 与任务的结构性 mismatch 共同决定。mismatch 负荷写成：

```text
L_i = w_A * A_i + w_U * U_i + w_D * D_i + w_M * M_i + w_F * F_i + w_R * R_i + sum_{j<k} w_jk * m_ij * m_ik
```

六个分量：`A_i` 聚合失配（aggregation mismatch，最优解需要全局聚合而非局部延续）、`U_i` 支持失配（support mismatch，高价值结构位于低支持区域）、`D_i` 状态失配（state mismatch，任务依赖当前通道下不可识别的外部隐藏状态）、`M_i` 规格失配（specification mismatch，目标本身不可完全形式化）、`F_i` 拟合边界失配（fitting-boundary mismatch，局部证据、指标或话术被绑定得太死，跨场景不稳健）、`R_i` 观测-表征失配（observation-representation mismatch，决定性变量没有进入模型可操作表征）。交叉项表示 mismatch 之间是超加性的：两种失配同时出现时的难度大于各自难度之和。

成功概率建模为受 mismatch 封顶的饱和函数：

```text
r_i(C,G,B) = r_min + [r_max(G,B,L_i) - r_min] * C^eta / (kappa_i^eta + C^eta)

r_max = sigmoid( a_i + beta_G * G + beta_B * log(1+B) - lambda_i * L_i^eff(G) )
L_i^eff(G) = L_irreducible + L_transformable * exp(-phi_i * G)
```

三个要点：

1. `r_max` 不是 1。即使 C 趋于无穷，纯自回归直接输出的成功率也会被有效 mismatch 卡住。
2. 工程治理 G 的作用，不是"增加模型能力"，而是**把可转化的 mismatch 转出模型**（检索和经验沉淀解 U_i、状态注入解 D_i、规格化 rubric 解 M_i、路由边界治理解 F_i、补测量与控制表征解 R_i），也就是降低 `L_i^eff`。
3. 推理预算 B 进入 `r_max` 的方式是对数的——这为第 6 章的 token 边际递减埋下伏笔。

### 2.3 支付意愿

客户比较两个期望效用：

```text
EU_i^AI = r_i * V_i - (1-r_i) * F_i - K_i
EU_i^H  = r_i^H * V_i - (1-r_i^H) * F_i - H_i
```

最高支付意愿是两者之差：

```text
P_i^* = max[ 0, (H_i - K_i) + (r_i - r_i^H) * (V_i + F_i) ]
```

这个公式有两个解读：

- **成本替代项** `H_i - K_i`：AI 方案省下的次优方案成本，减去自身全部成本。
- **可靠性溢价项** `(r_i - r_i^H)(V_i + F_i)`：成功率每提高一个百分点，价值是 `V_i + F_i`——既多赢一份成功价值，又少输一份失败损失。

由此可以推导出高价值任务的残酷性：高价值任务不仅 `V_i` 高，`F_i` 也高。如果 AI 的 `r_i` 不超过人类基线 `r_i^H`，可靠性溢价为负，`F_i` 越大罚得越重。**用户不会为"看起来很聪明"付高价，只会为"相对基线提高可靠性、降低风险、减少成本"付价。**

### 2.4 价格饱和

若纯自回归模式下成功率被卡在上限：

```text
lim_{C->inf} r_i(C, 0, B) = r_bar_i < 1
```

则无论模型多大，价格上限被锁死：

```text
lim_{C->inf} P_i^* = max[ 0, (H_i - K_i) + (r_bar_i - r_i^H) * (V_i + F_i) ]
```

突破这个上限的唯一途径不是更大的 C，而是用 G 降低 `L_i^eff`。这也是"卖模型"与"卖系统"的分水岭。

## 3. 市场动态：商品化如何吃掉稀缺租金

第 2 章是静态单笔定价。真实市场中，AI 能力本身会改变任务的价值。

### 3.1 稀缺性衰减

当模型能流畅完成某类任务、且该能力被市场比例 `m_i` 的参与者获得时，任务供给扩张，稀缺租金衰减：

```text
S_i(C, m_i) = exp[ -lambda_i * a_i(C) * m_i ]
V_i(C, m_i) = V_i^0 * S_i(C, m_i)
```

其中 `a_i(C)` 是能力可达度，`m_i` 是市场渗透率。代回支付意愿：

```text
P_i^* = max[ 0, (H_i - K_i) + (r_i - r_i^H) * (V_i^0 * S_i + F_i) ]
```

### 3.2 基线漂移

商品化还有第二条路径，常被忽略：`H_i` 本身不是常数。竞品工具普及后，客户的次优替代从"雇人类"变成"买便宜竞品"：

```text
H_i(t) = min( H_i^human, P_competitor(t) + switching_cost )
```

竞争把 `H_i` 压向竞品价格，`P_i^*` 随之塌缩到竞争均衡——通常只剩薄利。**稀缺性衰减打掉溢价的分子，基线漂移打掉成本替代的锚点**，两者叠加是商品化的完整机制。

### 3.3 驼峰曲线

对 C 求导可以看到价格的非单调性：

```text
dP_i^*/dC = (V_i^0 * S_i + F_i) * dr_i/dC      （正项：能力提升可靠性）
          + (r_i - r_i^H) * V_i^0 * dS_i/dC    （负项：能力加速普及）
```

早期 `dr_i/dC` 大、`S_i ≈ 1`，正项主导，价格上升；后期 `r_i` 饱和、`S_i` 衰减，负项主导，价格下降。于是任一任务的最高价格走出驼峰：

```text
不会做（价格 0）-> 刚会做且未普及（价格峰值）-> 人人都会做（价格塌向成本）
```

工具厂商的全部商业问题可以概括为一句话：**在驼峰顶部停留多久，以及驼峰过后还剩什么不可商品化的东西**。

## 4. 最高价格包络

把第 2、3 章合并，并引入价值捕获份额 `theta_i`（工具方在客户增量价值中实际能议价拿走的比例），得到完整定价式与包络上界：

```text
P_i^* = max[ 0, theta_i * { (H_i - K_i) + (r_i - r_i^H) * (V_i^0 * S_i + F_i) } ]

P_i^* <= theta_i * r_i(C,G,B) * S_i(C,m_i) * V_i^0 - K_i
```

`theta_i` 由议价结构决定：当价值实现依赖客户的 IP、专有数据、组织流程、监管牌照或分发渠道时，客户捕获大头，工具方 `theta_i` 低；当工具方绑定了验证管线、交付闭环或专有数据时，`theta_i` 高。

四个上限缺一不可：`r_i` 低则无物可卖；`S_i` 低则卖的东西不稀缺；`theta_i` 低则稀缺价值轮不到工具方；`K_i` 高则利润被成本吃掉。**第 5 章将逐行业检查这四个量。**

## 5. 行业最高支付价格估算

### 5.0 估算方法与口径

为使跨行业可比，统一采用如下简化口径：

```text
P_seat^* ≈ theta * rho * H_month
```

- `H_month`：该行业人类专业人员的月度全成本（薪酬 + 福利 + 管理摊销），作为价值锚点；
- `rho`：AI 可可靠替代或增产的有效产能比例（已按 `r_i` 折扣，即只计"可验证落袋"的部分，不计"演示流畅"的部分）；
- `theta`：竞争与议价结构下工具方实际可捕获的份额。

所有数字为**量级估算**（数量级与区间，非市场报价），人力成本以美国市场为参照系；按任务计价的行业改用 per-task 口径。每个行业按四上限逐项检查，并标注其在驼峰曲线上的位置。

### 5.1 软件开发

| 量 | 估算 | 依据 |
|---|---|---|
| `H_month` | $12,000–25,000 | 工程师全成本 $150k–300k/年 |
| `r_i` 现状 | 常规实现高；架构/遗留系统/调试受 `D_i`、`U_i` 限制 | 验证器（编译、测试、CI）强，`r_max` 高 |
| `F_i` | 中等 | 测试与回滚兜底，失败可逆 |
| `rho` | 20%–50% 有效产能提升 | 已按返工与审查折扣 |
| `S_i` 衰减 | 快 | 多家竞品同质，渗透率高 |
| `theta` | 5%–15% | 激烈竞争 + 客户自建选项 |

理论上限 `rho * H ≈ $2,500–12,000/座位/月`，但 `theta` 压缩后：

```text
P_seat^* ≈ $100 – $1,500 / 座位 / 月
（补全类靠近下界，自治 agent 类靠近上界）
```

**驼峰位置**：补全类已过峰；agent 化（多文件、长任务、自动验证）正在制造第二个小驼峰，但因竞品跟进速度快，预计峰宽更窄。

软件行业暴露了一个**可验证性悖论**：强验证器（编译器、测试）既是 `r_max` 高的原因，也是商品化快的原因——任何竞品都能用同一验证器达到同样可靠性，差异化无从建立。

**子案例：大型商业游戏。** 游戏是多要素生产函数：

```text
Q = F(P, A, D, S, I, M, L) ≈ min(P, A, D, S, I, M, L)
P=工程实现  A=美术  D=玩法设计  S=叙事  I=IP/世界观  M=发行  L=长线运营
```

若过去工程实现 P 是瓶颈，AI 编程工具的早期价值极高；但当所有厂商都能完成高规格实现，`P > min(其余要素)`，则 `dQ/dP ≈ 0`——继续提高编程能力对商业结果的边际贡献趋零。价值迁移到玩法、IP、审美、发行、社区与长线运营，而这些恰是 `M_i`（规格失配）与 `D_i`（状态失配）最重、`theta` 最归客户的环节。游戏公司对纯编程工具的支付意愿：

```text
P_tool^* = ΔC_code_saving + ΔR_speed + ΔR_quality
         - ΔR_crowding - K_integration - K_governance - K_risk
```

其中 `ΔR_crowding` 是全行业能力普及带来的拥挤损失。高价产品只可能来自"编程工具 + 专有 IP + 专有引擎 + 玩家数据 + 验证管线 + 制作治理"的绑定体。

### 5.2 法律服务

| 量 | 估算 | 依据 |
|---|---|---|
| `H` | $300–1,000/小时 | 律师费率 |
| `r_i` | 文档审阅/尽调/检索高；策略与出庭低 | 后者 `D_i`（对方隐藏状态）、`M_i`（说服不可形式化）重 |
| `F_i` | 极高 | 败诉、时效错过、执业责任 |
| `S_i` 衰减 | 文档类快；判断类慢 | |
| `theta` | 低 | 执业牌照与责任结构把价值留给持牌人 |

分层估算：

```text
文档审阅 / 尽调 / 合同初筛:  $10 – $100 / 文档批次（已接近商品化）
律所全流程助理:            $100 – $1,000 / 律师 / 月
诉讼策略与出庭判断:        theta ≈ 0，AI 无法独立销售此层
```

法律行业的关键约束是 `K_risk`：执业责任与无授权执业（UPL）监管使得 AI 输出必须经持牌人背书，人类治理成本 `K_supervision` 不可压缩，且 `theta` 被制度性锁低。高 `F_i` 在这里不是溢价来源而是 `theta` 杀手。

### 5.3 医疗

| 量 | 估算 | 依据 |
|---|---|---|
| `H` | $15,000–40,000/月 | 医生全成本 |
| `r_i` | 文书/病历高；诊断决策被 `U_i`（体征、病史外信息）与 `F_i` 卡死 | |
| `F_i` | 极端 | 误诊致害，单案赔偿 $10^6 量级 |
| `theta` | 制度性极低 | 监管不授予 AI 独立决策权 |

```text
临床文书 / scribe 类:    $100 – $600 / 医生 / 月（快速商品化中）
辅助诊断（嵌入设备/流程）: 按检查计价 $1 – $20 / 例，theta 归设备与流程方
独立诊断决策:            当前 theta ≈ 0
```

医疗展示了 `V_i` 与 `P_i^*` 的最大脱节：诊断价值极高，但 `F_i` 与监管把可销售形态限制在"辅助"。长期看，`theta` 的解锁不靠模型能力，靠**责任结构与验证管线的制度创新**——谁先建立可审计、可归责的验证闭环，谁拿走这层价值。

### 5.4 金融

| 量 | 估算 | 依据 |
|---|---|---|
| `H` | $15,000–50,000/月 | 分析师/风控全成本 |
| `r_i` | 摘要/数据整理高；alpha 发现结构性低 | |
| `F_i` | 高且不对称 | 错误交易、合规处罚 |
| `S_i` 衰减 | **alpha 类自毁性衰减**——全行业最陡 | |

金融是稀缺性衰减最极端的行业：alpha 的价值定义就是"别人不知道"。一旦某类信号可被通用模型挖掘，`m_i` 上升直接消灭 `V_i^0` 本身（不只是 `S_i`）：

```text
alpha 类任务:  V(m) -> 0 当 m -> 1，租金随普及自我清零
合规 / 风控:   F_i 高且结果可审计 -> 稳定付费区，$200 – $1,000 / 座位 / 月
投研 copilot:  $50 – $300 / 座位 / 月（快速商品化）
专有数据绑定系统: $1,000 – $3,000 / 座位 / 月
```

最后一档的参照系是传统金融终端（$2k+/月量级）的存在性证明：**高价从来不是模型撑起来的，是专有数据 + 网络效应 + 工作流锁定撑起来的**。模型只是把这个绑定体的交互成本降低了。

### 5.5 客服

| 量 | 估算 | 依据 |
|---|---|---|
| `H` | $3–15/工单；坐席 $3,000–5,000/月 | |
| `r_i` | 高（常见问题域窄、答案可验证） | |
| `F_i` | 低到中 | 个案损失小，品牌损失长尾 |
| `S_i` | 已塌缩 | 驼峰右侧的标本行业 |

```text
按结果计价:  $0.3 – $2 / 成功解决（resolution-based 已成主流口径）
上限锚点:    人类单票成本 × (1 - 客户留存的折扣要求)
长期走势:    趋向 边际token成本 + 薄利
```

客服证明了驼峰右侧的形态：`r_i` 高、`S_i` 低，定价被迫从"按座位"退到"按结果"，再被竞争压向成本线。工具方的出路只剩两条——绑定客户的知识库与业务系统（提高切换成本，即抬 `theta`），或纵向吃掉更复杂的工单（重新爬一个小驼峰）。

### 5.6 内容与营销

| 量 | 估算 | 依据 |
|---|---|---|
| `H` | $50–2,000/篇 | 写手/设计费率 |
| `r_i` | 流畅度高，品牌一致性与审美受 `M_i` 限制 | |
| `F_i` | 低（个案），中（品牌稀释长尾） | |
| `S_i` | 衰减最快，且伴随 V 的总量稀释 | |

内容行业有一个独特机制：AI 不仅商品化了生产能力，还**稀释了内容市场本身**——供给爆炸使单篇内容的注意力价值下降，`V_i^0` 整体缩水。这是比稀缺性衰减更彻底的价值破坏：

```text
通用写作工具:           $10 – $50 / 座位 / 月，趋向免费/捆绑
品牌资产+分发数据绑定系统: $500 – $5,000 / 团队 / 月
单篇内容:               $5 – $50 / 篇，长期趋向 0
```

价值迁移到分发渠道、品牌 IP 与受众数据——全部在客户或平台手里，`theta` 持续走低。

### 5.7 教育

| 量 | 估算 | 依据 |
|---|---|---|
| `H` | 家教 $30–100/小时 | 但支付方价格敏感 |
| `r_i` | 答疑/讲解高；长期动机管理与个性化受 `D_i` 限制 | |
| `F_i` | 低（短期），长尾（错误概念固化） | |
| `theta` | 低 | 消费级支付能力 + 效果归因困难 |

```text
消费级 AI 辅导:  $10 – $40 / 学生 / 月
机构/学校采购:   $5 – $20 / 学生 / 月（预算约束硬）
理论价值上限:    家教替代价值 $500 – $2,000 / 学生 / 月，但无法兑现
```

教育是 `V_i` 高而 `P_i^*` 低的典型：长期人力资本增值巨大，但**效果验证周期以年计、归因模糊**，支付意愿无法与价值创造对齐。这印证包络公式：没有可验证性，`V_i` 再高也进不了 `P_i^*`。

### 5.8 科研与药物发现

| 量 | 估算 | 依据 |
|---|---|---|
| `V_i` | 极端 | 缩短一年研发周期价值 $10^7–10^8 |
| `r_i` | 极低，且单次验证周期以月/年计 | `U_i`（湿实验数据）与 `D_i` 极重 |
| `F_i` | 高（错误方向的机会成本） | |
| `theta` | 取决于验证管线绑定 | |

`r_i` 低但 `V_i` 极端的组合使订阅制失效，定价走向期权结构：

```text
工具型（文献/假设生成）:  $10,000 – $100,000 / 课题组 / 年
管线合作（绑定湿实验验证）: 里程碑付款 + 分成，成功案例可达 $10^7 – $10^8
```

科研行业是包络公式的极限测试：`(r_i - r_i^H)(V_i + F_i)` 中 `V_i` 大到即使 `Δr` 只有几个百分点，溢价也巨大——但前提是这几个百分点**可被湿实验验证**。没有验证管线，一切假设生成都只是 token 消耗。

### 5.9 跨行业对比与规律

| 行业 | H 锚点 | F 量级 | r 现状 | S 衰减 | theta | P* 估算区间 | 驼峰位置 |
|---|---|---|---|---|---|---|---|
| 软件开发 | $12–25k/月 | 中 | 高 | 快 | 5–15% | $100–1,500/座位/月 | 过峰，agent 二次小峰 |
| 法律 | $300–1k/时 | 极高 | 分层 | 文档快/判断慢 | 制度性低 | $100–1,000/律师/月 | 文档层过峰 |
| 医疗 | $15–40k/月 | 极端 | 文书高/诊断低 | 文书快 | 极低 | $100–600/医生/月 | 文书层登峰 |
| 金融 | $15–50k/月 | 高 | 分层 | alpha 自毁性 | 数据绑定决定 | $50–3,000/座位/月 | 分层 |
| 客服 | $3–15/票 | 低中 | 高 | 已塌缩 | 低 | $0.3–2/解决 | 峰右侧 |
| 内容营销 | $50–2k/篇 | 低 | 高 | 最快+V 稀释 | 走低 | $10–50/座位/月 | 峰右侧 |
| 教育 | $30–100/时 | 低长尾 | 中高 | 中 | 低 | $10–40/学生/月 | 爬坡但 theta 封顶 |
| 科研药物 | — | 高 | 极低 | 慢 | 验证管线决定 | 里程碑 $10^7–10^8 | 远未到峰 |

四条跨行业规律：

1. **可验证性悖论**。验证器越强，`r_max` 越高，但商品化也越快（软件、客服）。稳态高价出现在"可验证但验证昂贵"的中间带——金融风控、法律合规、医疗审计——验证管线本身成为护城河。
2. **F_i 是双刃剑**。高失败损失既是可靠性溢价的放大器（若 AI 真能降风险），也是 `theta` 杀手（监管与责任结构把份额制度性地留给人类）。法律和医疗中后者压倒前者。
3. **支付意愿与价值创造系统性脱节**。脱节方向由验证周期决定：验证即时的行业（客服）价值低但变现顺畅；验证以年计的行业（教育、科研）价值高但变现受阻，定价被迫走向订阅折价或期权分成。
4. **长期高价只存在于绑定体**。所有行业中超过 $1,000/座位/月 的估算区间，无一例外要求绑定不可商品化资产：专有数据、IP、验证管线、监管牌照或组织流程。纯模型能力没有出现在任何一个高价区间里。

## 6. Token 经济学：从能力炫耀到边际 ROI

行业估算中反复出现的成本项 `K_i`，最容易被误判的部分是 token。公开 API 以 token 计费，token 天然可度量、可排行、可比较——但**可度量不等于可交付价值**。

当真实价值交付难以及时度量时，组织会把 token 消耗当作"努力程度、思考深度或能力强度"的代理指标。这个代理指标在早期产生兴奋，一旦采购者开始核算 ROI，就会被价值指标替代。

### 6.1 Token 是成本项，不是价值项

```text
Value(T) = r_i(T) * V_i - [1-r_i(T)] * F_i
         - c_T * T - K_latency(T) - K_governance(T) - K_oscillation(T)

MROI(T) = (V_i + F_i) * dr_i/dT
        - c_T - dK_latency/dT - dK_governance/dT - dK_oscillation/dT
```

理性停止条件：继续消耗 token 当且仅当 `MROI(T) > 0`。由第 2.2 节，B（即 T）以 `log(1+B)` 进入 `r_max`，`dr_i/dT` 天然递减；而 `c_T` 是常数，延迟与治理成本随 T 单调上升。**MROI 曲线必然下穿零点**，问题只是在哪里。

### 6.2 暴力反复采样的边际收益递减

若每次采样独立、单次命中近优解概率为 p，n 次采样命中率为：

```text
r_n = 1 - (1-p)^n
```

但真实 LLM 的候选输出高度相关。设候选间平均相关性为 rho_c，有效样本量近似为：

```text
n_eff = n / [1 + (n-1) * rho_c]
r_n = 1 - (1-p)^{n_eff}
```

当 `rho_c` 较高时，`n_eff` 随 n 增长迅速饱和（极限为 `1/rho_c`）。token 消耗近似线性增长，有效探索却停滞——这正是第 2.2 节 mismatch 封顶在采样视角下的镜像：**对高 mismatch 任务，模型的候选分布根本不覆盖近优解，采样再多也只是在错误的分布里抽签**。

### 6.3 把 token 与价值挖掘绑定

可操作的 token yield 指标：

- 每 1M token 带来的成功概率提升 `Δr / 1M tokens`；
- 每 1M token 发现的有效控制对象数：rubric、状态变量、edge case、约束、可撤销知识对象（GKO）；
- 每 1M token **通过外部验证**的候选数，而非生成候选数；
- 每 1M token 降低的人工审查时间、返工率或风险暴露；
- 每 1M token 触达的非冗余新信息或新状态，而非重写同一答案。

共同点：分子全部是可验证的状态改变，而不是文本产出量。

### 6.4 路由套利与 Token 杠杆率

近期一个高价前沿模型发布后，市场出现了一个很有解释力的现象：它的单 token 价格显著高于相邻的编码 agent，于是许多开发者自然形成了两段式工作流：

```text
高价模型:    压缩意图、写架构、定约束、产出规格文档
低价 agent:  展开执行、读文件、改代码、跑测试、反复修补
```

这不是偶然的使用习惯，而是一种理性的路由套利。用户把最贵的模型放在"高密度意图"环节，把最长的 token 尾巴交给便宜的执行层。它也解释了为什么 LLM 的 token 价格存在硬上限：真正决定支付意愿的不是某一个模型看起来多聪明，而是整条路由链路的总成本与可验证增量价值。

定义：

```text
T_I = intent tokens：规划、架构、约束、审查标准
T_E = execution tokens：文件读取、补丁、测试、重试、日志
L   = T_E / T_I       token leverage ratio（执行相对意图的放大倍数）
p_I = 意图 token 单价
p_E = 执行 token 单价
```

路由成本为：

```text
K_route = p_I * T_I + p_E * T_E + K_handoff + K_verification
        = T_I * (p_I + L * p_E) + K_handoff + K_verification
```

当 `L = 50`、`100` 甚至更高时，大部分 token 吞吐量会自然迁移到最便宜且足够可靠的执行层。高价模型只有在它的意图 token 能显著提高 `r_i`、降低 `L_i^eff`、减少返工或压缩执行尾巴时，才有权收取溢价。它的价格上限不是：

```text
高价模型单价 ≈ 模型智力光环
```

而是：

```text
p_I^* <= [可验证增量价值 - L * p_E * T_I - K_handoff - K_verification] / T_I
```

这会同时挤压链路两端。

**高价模型的 Oracle 陷阱。** 如果单价过高，用户会把它保留给低频、高密度的"军师"时刻，而把执行尾巴迁走。厂商获得了高单价，却失去了吞吐量、执行反馈和固定资产摊销效率。前沿模型背后是高固定成本资产：训练、推理集群、工程团队和能耗都需要被大量高价值调用摊薄。若模型只被当作少量架构建议源使用，表面 ARPU 可能很高，真实单位算力摊销却未必健康。

**低价执行层的毛利陷阱。** 低价 agent 承接了 `L` 倍的执行 token：文件扫描、失败重试、测试日志、局部修补、上下文刷新。它因此获得工作流位置和用户习惯，但也承担最重的边际成本。如果价格来自补贴、套餐或 seat 捆绑，而不是足够低的真实推理成本，那么 token 杠杆率会把增长变成毛利压力。使用量越成功，成本吞吐越大。

更关键的是，价值会穿过路由边界外泄。架构文档、规划树、rubric、验收标准和任务分解都是可携带的中间资产。一旦用户把高价模型提炼出的意图喂给低价执行 agent，稀缺价值就不再完全封闭在高价模型供应商内部。即使不假设任何训练数据回流，操作层面的价值也已经迁移到执行工作流里；如果相关产品条款允许保留日志、反馈或轨迹，这种迁移还可能变成"意图到执行"的数据飞轮。

因此，两段式套利更像过渡态，而不是稳态商业结构。它的长期均衡会向两端坍缩：

```text
高价意图层   -> 不再出售裸 token，而是出售闭环结果
低价执行层   -> 继续压低边际执行成本，出售受治理的吞吐量
```

高价层若想保住溢价，必须把规划、执行、验证和责任封装进同一闭环：不是卖"每百万 token 多少钱"，而是卖"完成一次可审计的迁移、重构、研究或合规交付"。只有结果计费、验证管线、专有上下文和责任结构绑定在一起，`theta_i` 才不会被用户路由走。

低价执行层若想长期承接 `L` 倍 token，就必须真的把边际执行成本打下来：更好的路由、更强缓存、更激进的蒸馏、更接近本地或边缘的推理、更短的工具循环、更少的无效重试。否则，低价不是护城河，而是把成本爆炸藏进增长曲线。

这个案例补充了本文的核心命题：当一个任务需要"高价模型负责构思，低价 agent 负责搬砖"才能经济上说得通，说明模型能力、token 消耗与价值捕获已经分裂。用户的真实支付对象不是哪一段 token，而是整条链路是否把意图变成了可验证状态改变。

## 7. 自我改进 Agent 的 State Oscillation

token 浪费最隐蔽的形态是自我改进循环。"反思—批评—重写—再批评"的隐含假设是价值随轮次单调提升。但若生成器、批评器、评估器共享同一个不完整的代理目标，且没有外部状态与强验证器，系统进入 state oscillation：

```text
z_{t+1} = A(z_t, critique_t, prompt_t) + epsilon_t
U_t = U(y_t; z_t, s)

可能的循环:  z_1 -> z_2 -> z_3 -> z_1 -> ...
```

agent 在几个局部合理状态之间震荡，而非朝真实价值收敛。震荡惩罚项：

```text
K_oscillation(T) = omega * Var(z_t | recent window)
                 + chi * ReversalRate(t)
                 + psi * UnvalidatedClaimGrowth(t)
```

判据很简单：**每一轮迭代是否产生了可复用、可验证、可撤销的控制对象**（新的约束、新的状态变量、新的已验证结论）。如果没有，每轮只是生成更多文本，本质仍是输出空间采样——token 越多，只是更昂贵的局部对齐。这也解释了为什么第 5 章高 `M_i`、高 `D_i` 行业（法律判断、玩法设计、科研方向）不能靠"让 agent 多想几轮"突破：震荡发生在错误的状态空间里。

## 8. 含义

### 对模型公司

- 从展示 token 消耗，转向展示 **value per token**：报告 Δr/1M tokens 与验证通过率，而非候选数量。
- 从直接输出，转向**控制空间产品**：状态矩阵、外部验证器、可撤销知识对象——这些降低 `L_i^eff`，是突破价格饱和的唯一杠杆。
- 从通用能力，转向与专有数据、工作流、验证管线的**深度绑定**——这是抬高 `theta` 与减缓 `S_i` 衰减的唯一杠杆。
- 按行业选择计价结构：高验证频率行业按结果计价（客服），长验证周期行业走里程碑分成（科研），中间带卖验证管线订阅（合规、风控）。
- 不要把裸高价 token 当作长期壁垒：只要用户能把意图导出给更便宜的执行层，溢价就会被路由套利击穿。

### 对购买方

- 先问任务是否仍有稀缺租金：竞争对手都能用同样工具完成的任务，不值得支付溢价。
- 核算真实 `Δr = r_i - r_i^H`，用己方验证标准测量，而非供应商演示的流畅度。
- 把 `F_i` 写进合同：高失败损失任务要求供应商共担风险，否则按低 `F_i` 任务付价。
- 要求供应商报告 token yield，拒绝为震荡与冗余采样的 token 付费。
- 把人类监督成本 `K_supervision` 计入总持有成本——它常常超过订阅费本身。
- 优先采购绑定己方专有数据与验证管线的系统：这同时提高 `r_i` 和己方在 `theta` 博弈中的地位。
- 按经验证的边际价值做模型路由，而不是按"聪明感"选模型；特别要核算从规划到执行的交接成本 `K_handoff`。

---

## 9. 结论

LLM 的最高价格不由"说得多流畅、推理多长、消耗多少 token"决定，而由它能否把 token、模型能力和工程治理转化为**可验证、可捕获、仍然稀缺**的任务价值决定。

四个命题：

1. 模型能流畅完成的任务迅速商品化：稀缺租金衰减叠加基线漂移，价格塌向成本线。
2. 模型不能流畅完成的任务仍然高价值，但依赖人类结构、工程治理和不可商品化资产，通用模型的可捕获份额受限。
3. token 只是成本和搜索预算；只有提高可达性、降低风险或产出可验证控制知识的 token 才转化为价值。
4. 当 token 消耗与价值挖掘绑定，市场从"能力炫耀与预算竞赛"回到"单位任务 ROI 与可靠交付"的理性定价。

```text
长期最高价格 = theta × (可验证增量价值 × 残余稀缺性) - token/治理/风险成本

而不是: 模型规模 + 推理长度 + 流畅输出感
```

行业证据与之一致：八个行业中没有任何一个高价区间由纯模型能力支撑；全部高价都长在验证管线、专有数据、IP 与组织闭环之上。模型公司卖的从来不该是 token，而是被验证过的状态改变。

多模型工作流同样服从这个结论。如果一个模型提供高密度意图，另一个模型吞掉执行尾巴，价格上限由整条路由链路决定，而不是由任一模型单独决定。高价模型必须把价值封装在结果、验证和责任闭环里；低价 agent 必须把执行 token 的边际成本真实打低。否则，市场只是在把"智能光环"重新翻译成更严酷的 token 账本。
